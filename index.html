Collage maker

Put photos side by side or in a grid, zoom them to the same spot, and save the lot as one picture.

On an iPhone, open the Share menu and pick Add to Home Screen to install this.

Steps

  1. Add the photos. They fill the cells in the order you picked them.
  2. Drag inside a cell to move the photo, and scroll or pinch to zoom.
  3. Zoom set to All photos moves them together, which lines up the same spot on a before and an after.
  4. Set Zoom to One photo when a shot was taken closer or further away, and size that one on its own until the subjects match. The percentage next to each photo tells you where you are.
  5. Tap a cell to select it, then type its label.
  6. Press Save.

Swipe

The Swipe tab lays the second photo over the first and gives you a divider to drag across. Saving there writes the divider where you left it, so the file shows the same split you were looking at.
